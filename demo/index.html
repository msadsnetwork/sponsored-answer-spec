MS Ads Sponsored Answer Spec v0.1 (draft)

An OpenRTB 2.6 extension for labelled sponsored answers in chatbots and AI agents. Illustrative demo with example data only.

Chat (example)

Mujhe university ke liye laptop chahiye, 150k se kam, Karachi delivery ho.
Core i5 ya Ryzen 5, 8–16 GB RAM aur SSD waala laptop is budget mein theek rahega. Neeche aik sponsored option hai.

The sponsored block is separate from the assistant's own answer. The label comes first, and the sponsor name is shown. The host sends no raw chat or personal data, only a short intent summary.
